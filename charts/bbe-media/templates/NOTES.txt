Sonarr, Radarr, Prowlarr, Bazarr and qBittorrent sign people in with Keycloak, and let in its admins.

Jellyfin and Seerr use their own login, which every app also has behind single sign-on:
{{- else }}

Every app's web UI uses the same login:
{{- end }}
  username: {{ .Values.bbe.admin.username }}
  password: kubectl get secret bbe-media-admin -n {{ .Release.Namespace }} -o jsonpath='{.data.password}' | base64 -d
{{- if .Values.bbe.setup.enabled }}

The apps are being connected to each other in the background, which can take a few minutes on a
first install. To follow along:
  kubectl logs -n {{ .Release.Namespace }} -f job/bbe-media-setup-{{ .Release.Revision }}
{{- end }}

Add indexers with `bbe configure {{ .Release.Name }}`, and Prowlarr shares them with Sonarr and Radarr.
Seerr signs in with the same login, through Jellyfin.
